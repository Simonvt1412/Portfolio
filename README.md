# Simon van Tomme - Portfolio

This is the personal portfolio of Simon van Tomme, a creative developer interested in interactive web experiences, 3D environments, physical computing, and digital installations.

The portfolio presents projects made with React, Three.js, React Three Fiber, Rapier, Arduino, Raspberry Pi, TouchDesigner, Blender, and other creative technologies. The work includes interactive 3D websites, concept development, commissioned installations, and collaborative student projects.

## Featured Work

- **[Driftveil City - Interactive 3D World](https://driftveil-city-website.vercel.app/)** - An interactive React Three Fiber recreation with custom 3D buildings, minigames, and Rapier physics.
  - [View the source code](https://github.com/Simonvt1412/driftveil-city-website)
- **E-Waste Shadow Trail** - An award-winning interactive coastal walk concept developed during a hackathon with The Cronos Group.
- **Vondelmolen Student Campaign** - A collaborative marketing campaign and storytelling website for students.
- **Beestige Tijdreizigers** - An RFID-controlled prehistoric animal racing installation built for Huis van Kina.
- **The ConneXion** - An interactive exoplanet-discovery installation created for Floralien Gent 2026.

## Running Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project for production:

```bash
npm run build
```

Run the linter:

```bash
npm run lint
```

The development server runs at `http://localhost:5173/` by default.

## Deployment

This is a Vite single-page application and is ready to deploy on Vercel. Import the GitHub repository into Vercel and use the default settings:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
